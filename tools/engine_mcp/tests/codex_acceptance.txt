use the available read-only tool search/discovery mechanism to locate engine_demo.

   to confirm the scene is empty and still exists. Do not delete or edit any other scene.

replace an uncertain write with a new request ID. If a tool errors, report that error
instead of using another mechanism to simulate success.

entity count before and after undo, and whether the values matched.
