   Query get_selection, use set_selection to select Cube, query again to confirm its ID.

   color [1,.02,.02], metallic .6, roughness .25 and use_texture false. Query to confirm.
5. Call capture_viewport with current session_id/scene_id/expected_revision and width=640,height=360.
   Inspect the actual image; report what is visible. Do not pretend success if no image is returned.

   from step 4 with its operation_id. Selection and screenshots must not consume that content undo.

   with both QA objects still present. Capture again and confirm a new frame_id and restored appearance.

For any error report it instead of simulating success with another mechanism.
Return a concise report: instance, QA scene_id, Cube entity_id, material operation_id,
two screenshot frame_ids/dimensions, material before/changed/restored, and image observations.
